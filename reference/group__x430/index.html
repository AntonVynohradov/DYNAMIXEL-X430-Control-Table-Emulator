    Group x430¶

    Modules > x430

    Device-side emulation of DYNAMIXEL X430 actuators over Protocol 2.0: the firmware moves any motor, the host sees an X430-compatible device. More...

    Detailed Description¶

    Parts. A bus (x430_bus) decodes the instructions of one serial line with DXL2-C and answers for its devices (x430_device). A device holds the Control Table of the model selected at build time and enforces the rules of the real actuator; the application connects it to its motor through x430_hooks. The optional simulator (x430_sim) replaces the motor.

    Execution model. Everything runs in one task context (an RX thread or the main loop), never in an interrupt: x430_bus_receive() with the bytes from the UART, x430_bus_poll() every few milliseconds (Bus Watchdog), and the live register updates of the application between x430_bus_lock() and x430_bus_unlock(). Hooks run inside x430_bus_receive() with the bus lock held.

    Platform access is done only through x430_bus_config::write (the bytes of a status packet), the optional x430_port (lock, millisecond clock, delay) and the hooks of each device.

    Initialization. Every function except the three *_init() functions returns X430_ERR_STATE for an instance without a successful initialization and calls no hook. An initialization checks every argument before it changes the instance: a refused initialization leaves the instance as it was.

    Public Functions Documentation¶

    function x430_bus_attach¶

    Attach an initialized device to an initialized bus. 

    int x430_bus_attach (
    struct x430_bus * bus,
    struct x430_device * device
)

    Takes the bus lock.

    Parameters:

    • bus Bus.
    • device Device, not attached to any bus.

    Return value:

    • X430_OK Attached.
    • X430_ERR_PARAM NULL pointer.
    • X430_ERR_STATE Bus or device not initialized, or the device is attached.
    • X430_ERR_CONFIG Bus full (X430_MAX_DEVICES) or the ID is used on the bus.

    function x430_bus_find¶

    Attached device with the primary ID id (lock-free). 

    int x430_bus_find (
    const struct x430_bus * bus,
    uint8_t id,
    struct x430_device ** device
)

    Parameters:

    • bus Bus.
    • id DYNAMIXEL ID.
    • device Set to the device, or to NULL when no device has that ID.

    Return value:

    • X430_OK Found.
    • X430_ERR_PARAM NULL pointer, or no attached device has the ID.
    • X430_ERR_STATE Bus not initialized.

    function x430_bus_handle_packet¶

    Handle one decoded instruction packet, for applications that run their own DXL2-C link. 

    int x430_bus_handle_packet (
    struct x430_bus * bus,

)

    Takes the bus lock; runs the hooks.

    Parameters:

    • bus Bus.
    • packet Packet decoded by DXL2-C. Status packets are ignored.

    Return value:

    • X430_OK (NULL pointer), X430_ERR_STATE (bus not initialized), X430_ERR_HAL (the writer failed).

    function x430_device_init¶

    Initialize a device: factory values, stored EEPROM area (nvm_read), the RAM area and the Startup Configuration (which may call the write hook). 

    int x430_device_init (
    struct x430_device * device,
    const struct x430_device_config * config
)

    Initialize a device before x430_bus_attach(), never while a bus serves it: the content of the instance before the call is not trusted (it may be the garbage of a stack instance), so an attachment cannot be detected.

    Parameters:

    • device Device, not attached to a bus.
    • config Configuration; copied (the hooks it points at are not).

    Return value:

    • X430_OK Device ready.
    • X430_ERR_PARAM NULL pointer or ID above 252.

    function x430_device_raise_hardware_error¶

    Report hardware errors (Hardware Error Status bits, lock-free). 

    int x430_device_raise_hardware_error (
    struct x430_device * device,
    uint8_t bits
)

    The bits stay set until REBOOT. Bits enabled in Shutdown (63) switch the torque off (event X430_EVENT_TORQUE_SHUTDOWN) and keep it off until REBOOT.

    Parameters:

    • device Device.
    • bits ::X430_HW_ERROR_* bits.

    Return value:

    • X430_OK (NULL), X430_ERR_STATE (not initialized).

    function x430_device_set¶

    Store a value into the register at address , ignoring access rights (lock-free). 

    int x430_device_set (
    struct x430_device * device,
    uint16_t address,
    int32_t value
)

    For live registers (Present Position, Moving, ...): no hook is called, no range is checked.

    Parameters:

    • device Device.
    • address First address of a register.
    • value Value; truncated to the register size.

    Return value:

    • X430_OK Value stored.
    • X430_ERR_PARAM NULL pointer, or no register starts at address.
    • X430_ERR_STATE Device not initialized.

    function x430_device_write¶

    WRITE semantics: checks every touched register, then calls the write hook and stores in address order; stores the EEPROM area when it changed. 

    int x430_device_write (
    struct x430_device * device,
    uint16_t address,
    uint16_t length,
    const uint8_t * data,
    uint8_t options,
    uint8_t * error
)

    Parameters:

    • device Device.
    • address First address.
    • length Bytes to write.
    • data length bytes.
    • options X430_WRITE_SECONDARY, X430_WRITE_VALIDATE_ONLY.
    • error Protocol result: DXL2_ERR_NONE or the DXL2_ERR_* of the first failure.

    Return value:

    • X430_OK (NULL), X430_ERR_STATE (not initialized).

    function x430_sim_init¶

    Prepare a simulator for device . 

    int x430_sim_init (
    struct x430_sim * sim,
    struct x430_device * device,
    const struct x430_sim_config * config
)

    Call it before x430_device_init() of a device whose hooks are x430_sim_hooks and whose user data is sim.

    Parameters:

    • sim Simulator.
    • device Device it simulates (may be initialized later).
    • config Configuration, NULL for the defaults.

    Return value:

    • X430_OK (NULL sim or device), X430_ERR_UNSUPPORTED (X430_FEATURE_SIMULATOR is 0).

    function x430_sim_step¶

    Advance the simulation by elapsed_ms one-millisecond steps and refresh the live registers. 

    int x430_sim_step (
    struct x430_sim * sim,
    uint32_t elapsed_ms
)

    Takes the bus lock of the device when it is attached. The time is proportional to elapsed_ms: call it periodically.

    Parameters:

    • sim Simulator.
    • elapsed_ms Time since the previous call [ms].

    Return value:

    • X430_OK (NULL), X430_ERR_STATE (simulator or device not initialized), X430_ERR_UNSUPPORTED (X430_FEATURE_SIMULATOR is 0).
