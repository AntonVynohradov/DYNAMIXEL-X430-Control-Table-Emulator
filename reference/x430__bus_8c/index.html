    function x430_frame_status¶

    Completes a status packet in place (no second buffer): header, id , the byte stuffing of instruction, error and data, the length field and the CRC. 

    size_t x430_frame_status (
    uint8_t * tx,
    size_t capacity,
    uint8_t id,
    uint16_t count
)

    The result is byte for byte the packet of dxl2_encode(). A status whose stuffed form does not fit capacity becomes a Data Length Error without data (the alert bit is kept).

    Parameters:

    • tx Packet buffer: error byte at offset 8, count data bytes from 9.
    • capacity Size of tx, at least 9 + count and at least 11 bytes.
    • id ID of the answering device.
    • count Status data bytes.

    Returns:

    Packet length (at least 11).
