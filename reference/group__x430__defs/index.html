    Detailed Description¶

    Control Table values come from the ROBOTIS e-Manual of the X430 models (https://emanual.robotis.com/docs/en/dxl/x/). Which registers a model really has is decided by its generated table: XL/XC models have no Current Limit (38) and Goal Current (102) and report Present Load at 126; XW models have no LED (65).
