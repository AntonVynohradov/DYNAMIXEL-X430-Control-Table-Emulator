
# Modules


Here is a list of all modules:


* [**DYNAMIXEL X430 Control Table Emulator API**](group__x430.md) _Device-side emulation of DYNAMIXEL X430 actuators over Protocol 2.0: the firmware moves any motor, the host sees an X430-compatible device._ 
    









    * [**Configuration**](group__x430__config.md) _Build-time configuration: Kconfig symbols or plain compiler definitions._ 
        

















    * [**Definitions**](group__x430__defs.md) _Status codes, options, events and the addresses, operating modes and bit fields of the X430 Control Table._ 
        






















































































































    * [**Model descriptor**](group__x430__model.md) _Types of the generated Control Table (one model per build)._ 
        


















    * [**Types**](group__x430__types.md) _Callbacks, configuration structures and the opaque instances._
